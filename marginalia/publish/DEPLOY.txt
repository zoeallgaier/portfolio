POST-FROM-YOUR-PHONE — setup (one time, ~5 minutes)
====================================================

1. Open index.php and change this line near the top to your own secret:
       $PUBLISH_PASSWORD = 'change-me-please';

2. Upload this whole `publish` folder to your site on SiteGround, into:
       marginalia/publish/
   (Site Tools → File Manager → open the `marginalia` folder → drag this
   `publish` folder in. Make sure the hidden .htaccess file comes along too —
   in File Manager, turn on "show hidden files" if you don't see it.)

3. On your phone, go to:
       https://YOURSITE/marginalia/publish/
   Enter your password, and bookmark the page / add it to your home screen.

That's it. Fill the form, tap Publish, and it's live on /marginalia/.

Notes
-----
- Photos are resized automatically, so posting straight from your camera roll
  is fine.
- If you ever get a "not writable" error, it means the server needs write
  permission on content.json or the _assets/marginalia folder — tell Claude and
  we'll fix the permissions.
- This page tells search engines not to index it, but the only real lock is
  your password, so keep it private.
